## Key design decisions

1. **Context menu via Radix `asChild`** — `ContextMenuTrigger` merges its props into the wrapped element (NodeWrapper's root div). No extra DOM inserted, no layout shift. The existing ref + onClick handlers stay intact.

2. **Rulers as siblings, not overlays** — A 2×2 grid (corner | H-ruler / V-ruler | content) keeps rulers pinned at the top-left of the scroll viewport. The inner tick track translates by `-scrollLeft`/`-scrollTop` so tick numbers correspond to the actual content position. Sibling layout avoids z-index/pointer-events issues that overlay approaches have.

3. **Asset manager mirrors AI assistant pattern** — Module-level `openState` + listeners Set; any ImageInput calls `openAssetManager({ currentValue, onChange })`. Mounts once in `editor-shell.tsx`. Selection writes the URL back to the field's `onChange`. TODO marker for Directus integration in Phase 3.

4. **Code view uses `renderToStaticMarkup`** — Wraps `<NodeRenderer>` in `EditorContextProvider` with `editable: false` so it produces clean HTML (no NodeWrapper, no selection chrome, no contentEditable attrs). Includes a minimal HTML5 doctype + `<style>` block injecting the design-token CSS vars so `var(--brand-*)` references resolve standalone. JSX constructed outside try/catch (linter rule), only `renderToStaticMarkup(tree)` is wrapped.

5. **Field grouping heuristic** — Each field's `group` + key is mapped to a GrapesJS-style section. `styles.background` → Background, `styles.textColor` → Typography, padding/margin/gap → Spacing, etc. Fields without an obvious home fall back to Layout (catch-all). The existing `FieldRenderer` interface is unchanged — only the right panel's grouping logic changed.

6. **Layers DnD reuses canvas pattern** — Separate `DndContext` (simpler than sharing with the canvas). Each row uses `useDraggable` + `useDroppable`. Grip handle is `opacity-0 group-hover:opacity-100` so click-to-select still works on the rest of the row. Drop position computed from cursor Y (top/bottom 50% = before/after, middle 40% on canvas nodes = inside). Same prev-index-shift correction as the canvas's `handleDragEnd`. Refuses to drop a node into its own descendant.

7. **Selection badge is IN ADDITION to the toolbar** — Toolbar shows on hover; badge is always on when selected. Badge uses `var(--brand-primary)` so it ties to the design system (changes color when the user changes the brand color).

8. **Double-click focuses first `[data-inline-text]`** — Uses `requestAnimationFrame` so the selection-driven re-render doesn't blow away focus. Caret placed at end of existing text (more natural than selecting all). Canvas-only components (no text fields) just select on double-click.
